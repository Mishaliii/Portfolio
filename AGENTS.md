# CareerLens Frontend

CareerLens is an editorial career intelligence platform built with React 19, TanStack Start/Router, and Tailwind CSS.

## Architecture

- **Frontend**: TanStack Router (`src/routes/`), React Query, Tailwind CSS.
- **Backend API target**: FastAPI (`/api/v1/*`), SQLAlchemy, SQLite/PostgreSQL.
- **Visual Direction**: Editorial Career Intelligence (warm ivory `#FBFAF6`, deep forest `#0B1A15`, muted green `#0D7A5F`, secondary stone `#F4F2EA`, muted gold `#C9A84C`).
- **Typography**: Newsreader (display/editorial headings) + Plus Jakarta Sans (UI body).
